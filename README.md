### 项目简介
本项目基于开源立方体项目设计拓展。项目以自主设计的立方体平台为载体，通过高速无刷电机驱动内部动量轮产生控制力矩，实现立方体在顶点、棱边上的动态平衡控制，并进一步拓展至自主起跳、地面站状态显示以及控制等功能。

本项目旨在融合嵌入式系统、电机控制、姿态解算以及无人机飞控相关技术，构建一个兼具科研价值与工程实践意义的综合实验平台。

### 材料选型
|  配件   | 选型  |
|  ----  | ----  |
| 主控MCU  | STM32H743VIT6 |
| IMU  | BMI088 |
| 蓝牙  | KT6368A |
| 磁力计  | QMC5883P |
| 电调  | 单体FOC无刷电调 |
| 电机  | T-MOTOR MN2806 |
| 结构  | 铝合金外框+铝柱 |
| 电池  | 4S 1100mAH锂电池 |
| 动量轮  | 铝合金动量轮 |

系统开发环境：Keil MDK5.38 + ARM Compiler V6.22 + CubeMX

### 通信接口：
|  硬件   | 接口类型  |
|  ----  | ----  |
| 蓝牙  | UART |
| IMU  | SPI |
| 磁力计  | I2C |
| 电调  | CAN |

### 通信协议：
蓝牙基于**MAVLink**协议通信，电调基于**DroneCAN**协议通信。

### 安全说明：
基于平衡立方体平衡原理，力矩由角加速度提供，平衡状态时如果施加较大扰动或者持续给力，期望角加速度突增使得动量轮轮速较大，需要**避免和动量轮接触**。
